# Technology Summit 2026 - Landing Page

A modern and responsive conference landing page built to practice and showcase core HTML5 and CSS3 styling techniques, custom typography, and structured layouts.

## 🚀 Overview

This project was developed with a strict focus on front-end styling fundamentals, featuring custom Google Fonts integration, FontAwesome icons, styled data tables, and interactive button states without relying on external UI frameworks.

## ✨ Key Features

* **Custom Typography & Google Fonts:** Integrated Google Fonts (Montserrat) with advanced text formatting including letter-spacing, word-spacing, line-height, and text shadows.
* **Structured Event Schedule Table:** A clean, custom-styled data table displaying event times, speakers, topics, and halls with alternating row highlights.
* **Interactive Button States:** Custom-styled anchor elements functioning as buttons with tailored `:hover` and `:active` visual feedback.
* **Responsive Container Layout:** Centered layout utilizing strict `max-width`, `min-width`, and automatic margins for optimal viewing.

## 🛠️ Technologies Used

* **HTML5:** Semantic markup and table structures.
* **CSS3:** Custom styling, nested CSS structure, box-sizing, and pseudo-classes.
* **FontAwesome:** Vector icons for visual enhancements in the schedule table.
* **Google Fonts:** External typography integration.

## 📁 Project Structure

* `index.html`: The main markup file containing the conference page structure and content.
* `style.css`: Custom stylesheet for layout positioning, typography, table design, and button interactions.
